# question-set：只交问题集

> 方案 `question-set`｜**不出卡**｜不需要 Anki 模型

## 什么时候用

用户只要"先出题"：整理复习清单、把讲义转成题库、考试前过一遍考点。这一步不写卡，也不需要 Anki。

## 用哪些能力，什么顺序

只用**资料整理**与**问题集整理**：

1. 资料整理：确认这批资料的层级（章节或题源），取出要覆盖的范围。
2. 问题集整理：按范围逐条出题，每题记：稳定 id、题干、题型、来源（页码/行号或题号）。

## 对象的硬要求

- 每题有稳定 id，重跑不会产生重复条目。
- 每题有来源；来源必须能回查（页行 / 题号 / URL 段落）。
- 题干问的是一件事；复合问题拆开。
- 有原题就照抄，不改写；自拟题标"自拟"。

## 呈现形式（可选）

默认交 Markdown 表格（id / 题干 / 题型 / 来源）。用户要列表、要按章节分组、要加难度列，都只是形式变化，
不改变上面四条对象要求。

## 什么情况停

- 资料范围不清楚（不知道覆盖哪几章）→ 先问。
- 出题时发现某段没有可问的点 → 跳过并在清单末尾记"未覆盖段落"，不硬凑题。

## 与出卡方案的关系

这份问题集可以直接交给 `qac-exam` 或 `qac-memory` 继续做卡——它们会接着用这些题和来源。
