# qac-exam：题源驱动 · 逐题取证（QAC 六字段）

> 方案 `qac-exam`｜产出卡型：QAC 六字段（序号树 / 表格）｜模板 `qac-v4`

## 什么时候用

手里**已有题目**（真题、题库、老师给的思考题），要按题找依据做成卡。
题目本身决定边界时用它；从章节出发生成问题用 `qac-memory`。

## 步骤

1. **列题**：题目原样列出，保留选项、题号、题源。**题干不改写、不调语序。**
2. **逐题取证**：按题干里的**小节标题词**（如"适应证""治疗原则"）定位，不按药名、病名。
3. **写答案**：只回答这道题问的那一件事；选项题保留正确选项的原文表述。
4. **写卡**：字段按下面硬要求；题源进引用。
5. **记忆提示**：针对这道题最易错的点写。

## 格式要求（硬性）

| 要求 | 怎么判 |
|---|---|
| 问题以「？」结尾 | 机器 `q-ask` |
| 题干照抄（可缩句），不改写、不调语序 | 人工对照原题 |
| 答案整段 `{{c1:: … }}`，不用 `<ul>`/`<ol>`/`**` | 机器 `a-open` / `a-close` / `a-no-list` |
| 答案只答本题，不扩大到整节 | 人工 |
| 要点数 = 答案可见字数 | 机器 `meta-length` |
| 引用以 `题源：` 开头 | 机器 `cite-source` |
| 引用含 `‖ p页:L起-止` | 机器 `cite-locator` |
| 选项题保留选项原文与题号 | 人工 |
| 一题两考点时拆卡，题源只跟原题走 | 人工；第二张标"拆分自同题" |

## 形式

- 选项并列、对比关系 → 表格（`<table class="pts">`，格内并列用 `<ol><li>`）。
- 单点问答 → 序号树。

## 正例

```
问题：哌唑嗪首剂为何要控制在 0.5mg 并卧床数小时？
章节定位：药理学（第10版） ‖ 第十一章 肾上腺素受体阻断药 ‖ 哌唑嗪
要点数：62字
答案：{{c1::<b>1.</b> 首剂易致晕厥，多为直立性低血压<br><b>2.</b> 给药：初始 0.5mg，
      睡前服，保持卧床数小时<br><b>3.</b> 目的：降低首剂晕厥风险}}
笔记：先想"为什么要防"，再记 0.5mg／睡前／卧床
引用：题源：药理学期末题库 第12题；药理学（第10版）, 人民卫生出版社 ‖ p120:L6-9
```

## 反例（各自违反哪条）

| 反例 | 违反 |
|---|---|
| 引用只写"药理学 p120" | `cite-source`（缺题源） |
| 答案把整节禁忌都写上 | 人工：只答本题 |
| 题干被改写成"请简述哌唑嗪" | 人工：题干照抄 |
| 一张卡塞两个问号 | 拆卡 |

## 什么情况回查、什么情况停

- 题干问的事，取到的原文回答不了 → 回查相邻段落；仍答不了就标"待补依据"，不自己编。
- 题目本身有争议或版本不一致 → 停，问用户以哪个为准。
- 题源缺失（不知道是哪次考试）→ 引用里写"题源：未注明"，并告诉用户。

## 验收

先跑一道题：题面、选项、题源、依据四样都对得上，再批量。
