# gaoshu-steps：数学推导 · 一步一动作

> 状态 **draft**｜卡型 QAC 六字段（条目化答案）｜模板 `qac-v4`
> 归纳自会话 `22bd9fc9-c7ee-4a0a-b9c7-c3961ac0353e`：同济《高等数学》第八版下册，36 节 371 张。

## 什么时候用

把教材里的**定理、公式、推导**做成卡。特点是答案天然分成若干动作或条件，
不能糊成一段；问题本身是**名词短语**，不是提问句。

不适用于：纯名词解释（用 `qac-memory`）、题库真题（用 `qac-exam`）。

## 步骤

1. **取原文**：按【节标题】找定理/公式，记页与节；不按概念词搜。
2. **判形态**：这张卡要回忆的是**结论**（条件 + 断言）还是**推导**（一步一动作）？
3. **写答案**：整段仍包在 `{{c1::…}}` 内，但内容拆成 `<ol><li>`，一条一个动作；
   条件、已知函数、公式左端都留在 c1 里，不搬到正面。
4. **写问题**：有主语、能独立看懂的名词短语。不写「怎么…」「什么叫…」，不以「？」结尾。
5. **填引用**：书目 + `‖ p页:L起-止`。
6. **打标签**：证明/推导卡打 `ai::derive`，便于以后单独筛。

## 硬性要求与判定

| 要求 | 判定 |
|---|---|
| 答案以 `{{c1::` 开头、`}}` 结尾，`}}` 后无尾巴 | 机器 `CLOZE` |
| `\(`/`\)`、`\[`/`\]` 成对；不出现双反斜杠 | 机器 `MATH_DELIM` |
| 公式内不出现裸 `<` `>`（会被 HTML 吃掉，改用 `\lt` `\gt`） | 机器 `MATH_ANGLE` |
| 公式内不出现 `}}`（会提前结束挖空） | 机器 `MATH_BRACE` |
| 答案有换行/分号/较长时，必须用 `<ol><li>` 条目化 | 机器 `STEPS` |
| 问题是名词短语：不以「？」结尾，不以「怎么/如何/什么…」开头，不少于 6 字 | 机器 `PROBLEM_FORM` |
| 不残留 Markdown（`**`、反引号） | 机器 `MD` |
| 条件与限定语不得省略；一步只做一次变形 | 人工（rubric） |
| 字当量与 180 上限 | **本方案未接管**（旧脚本对数学卡豁免） |

机器判据由本目录 `validate.mjs` 执行，`batch validate` 与 `card_write plan` 都会调用；
没有 JS 兜底之外的实现，也没有 Python 依赖。

## 正例

```
问题：格林公式的使用条件
答案：{{c1::<ol><li>闭区域 \(D\) 由分段光滑曲线 \(L\) 围成</li>
       <li>\(P,Q\) 在 \(D\) 上具有一阶连续偏导</li><li>\(L\) 取正向</li></ol>}}
引用：高等数学（第八版下册）, 高等教育出版社 ‖ p200:L12-20
```

## 反例

| 反例 | 违反 |
|---|---|
| 问题写成「怎么求三重积分」 | `PROBLEM_FORM`（自反性问句） |
| 问题只写「部分和」 | `PROBLEM_FORM`（秃名词，没主语） |
| `\(a<b\)` | `MATH_ANGLE`（裸尖括号） |
| 答案用「；」把两个动作糊成一段 | `STEPS` |
| 公式里写 `x^{n}}}` | `MATH_BRACE`（提前结束挖空） |

## 什么情况停

- 定理的前提在原文里分成几处、无法确认完整 → 停，先把条件补齐；缺条件的卡比缺内容的卡危险。
- 同一个定理在教材与手册里表述不同 → 以教材为准，并在笔记里注明差异。
- 一个问题里并了两个互不依赖的结论 → 拆两张，不压成一张。

## 验收

先做两张（一张结论卡、一张推导卡）确认条目粒度与公式写法；
批量时按标题先查重，再每 5 张一批发送——批量失败会整批回滚，小批才好定位。
