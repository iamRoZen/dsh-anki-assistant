# medical-qac-2026：旧实践归纳版（候选）

> 状态 **draft**｜卡型 QAC 六字段｜模板 `qac-v4`
> 归纳自旧 `schemes/medical_qac`、`~/.dsh/skills/anki-cards/SKILL.md`、`local/2026-11-16-surgery-*` 实践与 `tools/{measure,structure}.py`。

## 这套方案解决什么

把一段**有出处**的医学原文，做成一条能整体回忆的 QAC 卡：
问题只问一件事，答案是可按点核对的树（或同维度对照表），字当量压到考场长度，引用能回读。

## 步骤

1. **定位**：按【小节标题】找原文，不按概念词。记 `p<PDF页>:L<行>`；印刷页对不上时在引用里注明。
2. **判根数**：答案缩成顶层，是一个根还是两个互不依赖的根？两个 → 拆两张。
3. **判形状**：原文用编号分层 → 序号树；同一维度行列对照 → 表格。依据原文，不依据好看。
4. **写骨架**：只写编号与分支名，一个内容词都不填。
5. **填内容**：一个叶子一个判断；单行超过 25 字当量就回去拆。
6. **压缩**：删措辞，不删层级、限定语、方向、阈值。
7. **写字段**：答案整段 `{{c1::…}}`；要点数按字当量实算；笔记只写记忆提示。

## 硬性要求与判定方式

| 要求 | 判定 |
|---|---|
| 问题以「？」结尾 | 机器 `q-ask` |
| 答案以 `{{c1::` 开头、`}}` 结尾，且 `}}` 后无尾巴 | 机器 `a-cloze`（尾巴会静默丢失） |
| 字当量 ≤180（硬上限，不随点数放宽） | 机器 `a-weight` |
| 序号 `<b>1.</b>/<b>1.1</b>` 必在块首；父子齐全、同级连号 | 机器 `a-ordinal` |
| 单行 ≤25 字当量；`<li>` 每项单独算一行；表格不参与 | 机器 `a-lines` |
| 表格一格内 ≥3 项且有「或／」这类择一标记 → 必须再起 `<ol><li>` | 机器 `a-table` |
| 要点数 = 答案字当量 | 机器 `meta-weight` |
| 章节定位含全角 ‖ | 机器 `loc-form` |
| 引用含 `‖ p页:L起-止` | 机器 `cite-locator` |
| 分支名有出处；两个根就拆；记忆提示不复述答案 | 人工（rubric） |

机器规则由 `card_write plan` / `batch validate` 在草稿阶段实际执行，不是文档约定。

## 形式

- 序号树：`<b>1.</b>` / `<b>1.1</b>` 放段首，父先于子。
- 表格：`<table class="pts">`，首行 `<th>`，格内并列用 `<ol><li>`。
- 表格只用于**同一维度**的行列对照；去掉一行就丢关系时尤其如此。
