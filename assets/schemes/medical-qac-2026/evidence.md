# 依据台账：规则 → 出处

图例：**强** = 有代码或逐条文档可查；**中** = 有实践产物但无过程记录；**依据不足** = 只有成品或口头印象。

## 用户反复要求的标准

| 规则 | 出处 | 强度 |
|---|---|---|
| 字当量 = 汉字 + ASCII/2 + Σ max(起价, 源码长/2)；行间起价 15、行内 4 | `tools/measure.py` L33-72 | 强 |
| 手写序号不计入字当量 | `tools/measure.py` L40 | 强 |
| 180 是硬上限，不随点数放宽 | `schemes/medical_qac/check.py` L36 | 强 |
| 序号必须块首、父子齐全、同级连号 | `tools/structure.py` L18-31；`check.py` L50-74 | 强 |
| 单行 25 字当量；`<li>` 单独成行；表格免检 | `check.py` L37、L98-118 | 强 |
| 表格格内 ≥3 项且有择一标记要再分层 | `check.py` L131-163 | 强 |
| `}}` 之后挂尾巴属静默丢失，必须报 | `tools/structure.py` L68-85 | 强 |
| 答案整段 c1 包裹、笔记留空 | `SKILL.md`「字段」表 | 强 |
| 引用带 `‖` 定位串，行号口径以页眉为第 1 行 | `SKILL.md`「引用与定位串」 | 强 |
| 先骨架后填字；压缩不删层级 | `SKILL.md` 第 4–7 步与教训段 | 强 |

## 某道题/某次任务的临时决定

| 决定 | 出处 | 处理 |
|---|---|---|
| 这张卡用表格而不是序号树 | 各实践 review.md 的逐卡判断 | 不进规则，留给"判形状"时按原文定 |
| 这一题拆成两张而不是一张 | 同上（NHL 案例被拆） | 写成 rubric 的判根数要求，不做机器规则 |
| 单卡篇幅压到某个具体字数 | 旧 `cli check` 的运行时参数 | 只保留 180 上限；更紧的阈值属任务要求 |
