# qac-memory：教材驱动 · 概念关系出题（QAC 六字段）

> 方案 `qac-memory`｜产出卡型：QAC 六字段（序号树 / 表格）｜模板 `qac-v4`

## 什么时候用

要把**一节教材**变成题：先看这一节讲了哪几组关系，再决定出几道。
题源驱动（`qac-exam`）走另一条路：题目已存在，逐题找依据。两者出同一种卡，但取材路径不同。

## 步骤

1. **归组**：读目录层级与本节小节标题，把内容归成几组关系（定义 / 分型 / 机制 / 表现 / 处理）。不先逐段读正文。
2. **出题**：一组关系一道题。宁可少出，不把一个关系切成碎片。
3. **取证**：回到该小节取原文，记 `p<PDF页>:L<行>`；印刷页写进定位做对照。
4. **写答案**：按原文编号写成树，再压缩。
5. **写卡**：字段逐项按下面的硬要求；形式按内容结构选。
6. **记忆提示**：写进"笔记"。

## 格式要求（硬性）

| 要求 | 怎么判 |
|---|---|
| 问题以「？」结尾 | 机器 `q-ask` |
| 问题不含选项字母（`A．` 之类） | 机器 `q-no-option` |
| 问题里不出现答案的关键词 | 人工（出现即泄题） |
| 章节定位含全角 `‖`，节名照目录原文 | 机器 `loc-form` + 人工核对标题 |
| 答案整段 `{{c1:: … }}` | 机器 `a-open` / `a-close` |
| 答案不用 `<ul>`/`<ol>`/`**` | 机器 `a-no-list` |
| 答案 ≤220 字；单行 ≤25 字 | 机器 `a-length` + 人工看行长 |
| 序号 `<b>1.</b>` / `<b>1.1</b>` 放段首，父先于子 | 人工 |
| 要点数 = 答案可见字数 | 机器 `meta-length` |
| 引用含 `‖ p页:L起-止` | 机器 `cite-locator` |
| 笔记不复述答案首句 | 人工 |
| 表格只用于同一维度的行列对照 | 人工（判断在正文"形式"一节） |

机器判的写在方案记录的 `quality.rules` 里，改一条会生成 v+1；人工判的写在 `quality.rubric` 与正文，由你按原文核。

## 形式：序号树还是表格

- 原文是并列或分层 → 序号树。
- 同一维度上的行列对照（几类 × 几个属性）→ 表格；去掉一行就丢关系时尤其如此。
- 判断依据是原文长什么样，不是哪种更好看。

## 正例

```
问题：哌唑嗪的不良反应按发生率如何排列？
章节定位：药理学（第10版） ‖ 第十一章 肾上腺素受体阻断药 ‖ 哌唑嗪
要点数：60字
答案：{{c1::<b>1.</b> 晕厥：多由直立性低血压引起<br><b>2.</b> 发生率由高到低：
      眩晕、头痛、嗜睡、精神差、心悸、恶心<br><b>3.</b> 多发生在服药初期，可耐受}}
笔记：晕厥单独挂机制；排序记成一条下坡路
引用：药理学（第10版）, 人民卫生出版社 ‖ p120:L10-11
```

## 反例（各自违反哪条）

| 反例 | 违反 |
|---|---|
| 六条平铺、每条都带主语 | 层级被压平（人工判） |
| 问题写成"哌唑嗪的晕厥和禁忌分别是什么？" | 一题两问，拆卡 |
| 答案用 `-` 列表 | `a-no-list` |
| 引用写"见教材第十一章" | `cite-locator`，回查不到 |
| 要点数手填 `5字` | `meta-length`，按答案实算 |

## 什么情况回查、什么情况停

- 某组关系在原文找不到对应小节 → 回查目录，可能属于上一节；仍找不到就停，说明缺哪组。
- 答案里的分支名不是原文标题的词 → 回查原文；原文没有就不写。
- 一组关系能拆成两个互不依赖的点 → 拆两道，不压成一道。

## 验收

样卡 2–3 张经用户确认后再批量；验收看四件事：定位能回查、答案能逐点对照原文、
每张卡的格式要求都过、记忆提示确实在教怎么背。
