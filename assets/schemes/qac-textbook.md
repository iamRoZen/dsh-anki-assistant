# qac-textbook：教材驱动 · 概念关系 → 问题

> 方案 `qac-memory`｜出卡｜模板 `qac-v4`

## 什么时候用

目标是**把一节教材变成问题**。适合概念多、结构清晰的章节：先看这一节讲了哪几组关系，再决定出几道题。

## 用哪些能力，什么顺序

1. **资料整理（章节入手）**：先读**目录层级**，再看这一节的**小节标题**，把内容归成几组关系
   （定义 / 分型 / 机制 / 表现 / 处理）。不先逐段读正文。
2. **问题集整理**：每一组关系出一个问题。一组关系只出一道，宁可少出，不把一个关系切成碎片。
3. **撰写答案**：回到原文取那几组关系对应的行，按原文的编号写成树。
4. **制作卡片**：按模板填六个字段；形式按内容结构选（并列/分层用序号树，行列对照用表格）。
5. **制作记忆指导**：写进"笔记"字段。

## 什么情况回查、什么情况停

- 归组时发现某一组在原文里找不到对应小节 → 回查目录，可能这组属于上一节；仍找不到就停，说明缺哪组。
- 答案里的分支名不是原文标题里的词 → 回查原文；原文没有这个词就不写。
- 一个问题里并了两个互不依赖的关系 → 拆成两道，不压成一道。

## 验收

- 每个问题对得上原文某一个小节或某一段编号。
- 答案的分支名来自原文标题。
- 每个答案能顺定位回读。

## 与其他方案的区别

题源驱动（`qac-exam`）从**已有的题**出发，逐题找证据；本方案从**章节结构**出发，先生成问题再找证据。
两者都能出同一种卡，但取材路径与出题数量不同。
